# Dynamic Island для Windows

## Как запустить

- **Ярлык на рабочем столе:** `Dynamic Island` →
  `C:\Users\user\DynamicIsland\user\DynamicIsland.exe`
- Или напрямую: `C:\Users\user\DynamicIsland\dist\DynamicIsland.exe`

Приложение одноэкземплярное: повторный запуск просто ничего не делает.
Свернуть в трей / показать обратно — через иконку в системном трее.

## Управление

| Действие | Что делает |
|---|---|
| Навести курсор на пилюлю | Раскрывает карточку |
| ЛКМ по островку | Закрепить / открепить раскрытое состояние |
| ПКМ по островку | Настройки (погода, часы, батарея, город, скрытие в фуллскрине, выход) |
| Перетащить файл на островок | Открывается зона приёма, файлы остаются на полке |
| Навести файл на островок и отпустить | Файл сохраняется на полке |
| Прокрутка над полкой | Листать файлы (полка видна только при перетаскивании) |
| Иконка в трее | Показать/скрыть, автозапуск, «Очистить полку», выход |

## Что умеет

- Музыка через Windows SMTC: обложка, трек, исполнитель, перемотка, play/pause.
- Погода через Open-Meteo (город можно задать в ПКМ-меню, иначе определяется по IP).
- Часы, дата, заряд батареи — включаются в ПКМ-меню, по умолчанию скрыты.
- Полка файлов: не занимает место в обычном виде, появляется при поднесении файла.
- Полноэкранный режим: островок улетает вверх и возвращается, когда приложение закрыто.
- Не попадает в панель задач и Alt+Tab, не забирает фокус у игр.

## Требования

- Windows 10 20H1+ / Windows 11
- .NET 10 Desktop Runtime (или установленный .NET 10 SDK)

## Настройки и данные

- `%APPDATA%\DynamicIsland\settings.json` — настройки и полка
- `%APPDATA%\DynamicIsland\log.txt` — журнал ошибок

## Сборка из исходников

```powershell
cd C:\Users\odifr\DynamicIsland
dotnet build
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o dist
```
