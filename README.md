# Dynamic Island for Windows

Интерактивный виджет для рабочего стола Windows 10 и 11, вдохновлённый Dynamic Island от Apple. Приложение выводит информацию о мультимедиа, погоде, времени и заряде батареи, а также служит удобным буфером для быстрого доступа к файлам.

## ✦ Возможности

* **Мультимедиа** — интеграция с Windows SMTC: отображение обложки альбома, названия трека и исполнителя, а также управление воспроизведением и перемоткой.
* **Погода** — актуальный прогноз через Open-Meteo API с автоматическим определением геолокации по IP или ручным выбором города.
* **Часы и дата** — компактное отображение текущего времени и календарной даты.
* **Питание** — индикатор текущего уровня заряда аккумулятора устройства.
* **Файловая полка** — временное хранилище для перетаскиваемых файлов (Drag-and-Drop) с быстрым доступом к ним в один клик.
* **Полноэкранный режим** — автоматическое скрытие виджета при запуске игр или полноэкранных программ и возврат после их закрытия.
* **Системный трей** — быстрое управление видимостью, автозапуском и параметрами через значок в области уведомлений.

## ❖ Интерфейс и управление

| Действие | Результат |
| :--- | :--- |
| **Наведение курсора** | Плавное раскрытие панели Dynamic Island |
| **Левая кнопка мыши (ЛКМ)** | Фиксация или открепление раскрытого состояния |
| **Правая кнопка мыши (ПКМ)** | Открытие контекстного меню настроек |
| **Перетаскивание файла на панель** | Активация режима файловой полки |
| **Отпускание файла над панелью** | Добавление файла во временное хранилище |
| **Колесо мыши над полкой** | Прокрутка и переключение между сохранёнными файлами |
| **Клик по иконке в трее** | Скрытие или отображение виджета на экране |

### ⚙ Настройки

Через контекстное меню виджета доступно управление следующими параметрами:
* Включение и отключение виджета погоды, а также выбор города.
* Настройка формата отображения часов и даты.
* Включение индикатора уровня заряда батареи.
* Активация скрытия панели в полноэкранном режиме.
* Завершение работы приложения.

Дополнительно в меню системного трея доступны включение **автозапуска вместе с Windows** и **очистка файловой полки**.

## ▶ Установка и запуск

### Готовая сборка
1. Скачайте и распакуйте архив с последней версией приложения.
2. Запустите исполняемый файл `DynamicIsland.exe` или воспользуйтесь ярлыком на рабочем столе.

*Примечание: Приложение работает в режиме одного экземпляра (Single Instance) — повторный запуск не создаст дублирующее окно.*

### Системные требования
* **ОС:** Windows 10 (версия 20H1 и новее) или Windows 11.
* **Архитектура:** x64.
* **Компоненты:** [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64).

## ⚒ Сборка из исходного кода

Для самостоятельной компиляции потребуется установленный [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```powershell
   git clone <REPOSITORY_URL>
   cd DynamicIsland
   ```

2. **Выполните сборку и публикацию в один исполняемый файл:**
   ```powershell
   dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o dist
   ```

Готовый файл `DynamicIsland.exe` появится в директории `dist`.

## ▤ Хранение данных

Все конфигурации и журналы работы хранятся локально в директории пользователя:
```text
%APPDATA%\DynamicIsland\
```

| Файл | Назначение |
| :--- | :--- |
| `settings.json` | Пользовательские настройки и список файлов на полке |
| `log.txt` | Журнал событий и отладочная информация об ошибках |

## ◈ Технологический стек

* **Язык и платформа:** C# / .NET 10 (Windows Desktop)
* **Интеграции:** Windows SMTC (System Media Transport Controls)
* **Внешние API:** Open-Meteo API

## ▪ Технические особенности

* **Ненавязчивость:** окно не отображается на панели задач и в меню переключения окон (`Alt + Tab`).
* **Безопасность фокуса:** виджет не перехватывает фокус ввода у активных окон и полноэкранных игр.
* **Лёгкость:** минимальное потребление ресурсов в фоновом режиме.
