# Dynamic Island for Windows

Современный Dynamic Island для Windows 10/11 — интерактивный элемент рабочего стола, вдохновлённый Dynamic Island от Apple.

Приложение отображает информацию о воспроизводимой музыке, погоде, времени и состоянии батареи, а также предоставляет удобную систему быстрого доступа к файлам.

## ✨ Возможности

- **Музыка** — интеграция с Windows SMTC: обложка альбома, название трека, исполнитель, управление воспроизведением и перемотка.
- **Погода** — текущая погода через Open-Meteo. Поддерживается автоматическое определение местоположения по IP и ручной выбор города.
- **Часы и дата** — отображение текущего времени и даты.
- **Батарея** — отображение текущего уровня заряда устройства.
- **Файловая полка** — временное хранение файлов с возможностью быстрого доступа через Dynamic Island.
- **Полноэкранный режим** — Dynamic Island автоматически скрывается при запуске полноэкранных приложений и возвращается после их закрытия.
- **Системный трей** — управление приложением, автозапуском и настройками через иконку в системном трее.

## 🖥️ Интерфейс и управление

| Действие | Результат |
|---|---|
| Наведение курсора | Раскрытие Dynamic Island |
| ЛКМ | Закрепление или открепление раскрытого состояния |
| ПКМ | Открытие меню настроек |
| Перетаскивание файла | Активация файловой полки |
| Отпускание файла | Добавление файла на полку |
| Прокрутка над полкой | Переключение между файлами |
| Нажатие на иконку в трее | Управление видимостью приложения |

### ⚙️ Настройки

Через контекстное меню доступны:

- Включение и отключение погоды.
- Настройка отображения часов и даты.
- Отображение уровня заряда батареи.
- Выбор города для погоды.
- Скрытие Dynamic Island в полноэкранном режиме.
- Выход из приложения.

В системном трее также доступны управление автозапуском и очистка файловой полки.

## 🚀 Установка и запуск

### Запуск готовой версии

После установки или распаковки приложения запустите:

```text
DynamicIsland.exe
```

Также можно использовать ярлык на рабочем столе.

Приложение поддерживает режим одного экземпляра: повторный запуск уже работающего приложения не создаёт дополнительное окно.

### Системные требования

- Windows 10 (20H1 и новее) или Windows 11.
- .NET 10 Desktop Runtime.
- Архитектура x64.

## 🛠️ Сборка из исходного кода

### 1. Установка

Установите [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

### 2. Клонирование репозитория

```powershell
git clone <REPOSITORY_URL>
```

### 3. Переход в директорию проекта

```powershell
cd DynamicIsland
```

### 4. Сборка проекта

```powershell
dotnet build
```

### 5. Публикация приложения

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o dist
```

Готовое приложение появится в директории `dist`.

## 📁 Хранение данных

Все пользовательские настройки и данные приложения хранятся локально:

```text
%APPDATA%\DynamicIsland\
```

| Файл | Назначение |
|---|---|
| `settings.json` | Настройки приложения и данные файловой полки |
| `log.txt` | Журнал работы и ошибок |

## 🔧 Технологии

- C# / .NET 10

## 📌 Особенности

- Не отображается на панели задач и в Alt+Tab.
- Не перехватывает фокус у полноэкранных приложений и игр.
- Поддерживает работу в системном трее.
- Не создаёт дополнительных экземпляров при повторном запуске.
